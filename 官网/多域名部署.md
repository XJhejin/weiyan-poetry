# 公共站点的域名入口

两个新域名均连接现有服务器 `156.225.28.175`，共用已经部署的网页、安装包和 Discuz! 数据库。

| 内容 | 原域名 | 新入口 |
| --- | --- | --- |
| 官网与软件下载 | `www.hushleaf.top` | `7me.top`、`www.7me.top`、`weiyan.ink`、`www.weiyan.ink` |
| 未言诗集社区 | `bbs.hushleaf.top` | `bbs.7me.top`、`bbs.weiyan.ink` |
| 未言诗个人主页 | `weiyan.hushleaf.top` | `weiyan.7me.top`、`weiyan.weiyan.ink` |
| 聊天服务 HTTPS | `156.225.28.175:23074` | `7me.top:23074`、`weiyan.ink:23074` |

各入口均使用 HTTPS，HTTP 自动跳转至相同域名的 HTTPS。论坛账号、帖子和附件共用一套数据；不同域名的浏览器登录状态独立，需要在所用域名登录。现有聊天客户端连接地址继续使用 `https://156.225.28.175:23074`。

在两个域名的 DNS 后台将 `@`、`www`、`bbs`、`weiyan` 的 A 记录指向服务器，移除冲突的旧地址及未配置的 AAAA 记录。部署脚本只为解析正确的入口启用配置，未完成的入口会在 `pending_dns` 中列出；修正解析后重复部署即可补齐。

`tools/deploy_domains.py` 在临时管理员 SSH 会话中运行，不保存密码或新增 SSH 授权。它从当前生效的三个公共站点复制路由，保留原有访问限制、附件大小、PHP 配置及安全响应头；新入口直接使用原站目录。脚本拒绝覆盖不属于自己的同域名站点，部署前备份配置并由网站代理运行账号验证，部署后检查受信任 HTTPS、服务器下载、论坛敏感目录限制以及原服务健康，失败恢复代理配置。

配置位于 `/etc/weiyan/Caddyfile` 的 `HushLeaf domain aliases` 区块及 Nginx 的 `hushleaf-domain-aliases.conf`，备份和结果位于 `/opt/weiyan/domain-aliases/`。更新网页、帖子或下载安装包会自动反映到所有入口；更改原站路由或安全策略后，应重新执行此脚本同步入口配置。`--verify` 仅检查已配置域名与原服务。
