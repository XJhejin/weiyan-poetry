# 未言诗集 · HushLeaf 官网

域名 `www.hushleaf.top`，A 记录指向 `156.225.28.175`。官网和所有安装包由该服务器提供，浏览器下载不会跳转 GitHub。静态网页没有外部字体、CDN、统计脚本或登录功能。

`7me.top`、`weiyan.ink` 及对应子域名的入口映射、共享数据方式与维护流程见 [多域名部署](多域名部署.md)。

`tools/build_site.py` 仅接受内置发布公钥验证通过的清单；逐包核对大小、SHA-256 后生成独立静态目录。正式版本为 2.2.2。页面中的下载地址在构建时写入，关闭 JavaScript 也能下载。

`tools/deploy_site.py` 通过一次性管理员 SSH 会话运行：服务器先获取固定版本的签名清单和安装包，验证后构建站点；备份现有 Caddyfile，保留聊天端口 23074 和原有代理配置，追加域名 HTTPS 站点。切换前验证配置，切换后检查官网受信任 HTTPS 以及聊天健康接口，失败自动恢复站点链接及 Caddy 配置。它不修改 SSH 授权，不读取或公开聊天数据库。

服务器目录：`/opt/weiyan/website/versions/` 存放完整站点版本；`current` 指向当前公开目录；`releases/` 缓存签名安装包；`deployment.json` 记录部署结果。仅 `current` 目录由 Caddy 提供，未开启目录浏览。管理 API 仍只监听本机回环。

维护时先完成软件构建、集成测试与签名发布，再使用已有控制端更新 Linux 服务端，然后通过管理员 SSH 运行：

```sh
/opt/weiyan/control/venv/bin/python 官网/tools/deploy_site.py --version 2.2.2
```

输入代码路径需来自本仓库对应已核对提交，Python 环境需可导入当前服务端的 `update.py`。安装脚本只打开官网必需的 443/TCP；公网防火墙也需放行 443。域名 HTTPS 证书由 Caddy 使用 443 端口的 TLS-ALPN 验证自动申请及续期，不占用原有 Nginx 的 80 端口。官网请使用完整地址 `https://www.hushleaf.top/`；80 端口的现有网站配置保持原样。
