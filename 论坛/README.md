# HushLeafBBS · 未言诗集

基于 Discuz! 官方简体中文开源版的社区站点，提供未言诗集原创浅粉主题、羽毛笔标志和独立部署工具。

论坛地址：https://bbs.hushleaf.top/

管理后台：https://bbs.hushleaf.top/admin.php

发帖、回复、附件、搜索、私信、会员、版主、门户、圈子及后台管理均使用 Discuz! 原生功能。桌面与手机端统一品牌外观，手机浏览器自动使用原生移动界面。

原创媒体插件为电脑和手机编辑器增加视频、音频、网页插入及尺寸设置，本地媒体通过原生附件接口上传，单文件最大 1 GB；播放器保留原生附件访问权限。手机帖子同时显示作者签名，遵守匿名、封禁及原有签名设置。

发帖或回复时点击“视频”或“音频”，默认进入“上传附件”，手动选择本机文件，设置播放器大小后点击“插入”，最后发布帖子。文件保存在论坛服务器，作为该帖原生附件管理；也可切换“网络链接”插入 HTTPS 媒体。手机端可直接使用系统文件选择器。

电脑完整编辑器原有的音频、视频图标同样打开此上传窗口，支持富文本和源码模式；插入内容保留原光标位置，切换工具栏后仍然有效。

部署时对固定版本的原生 JavaScript 语言加载器应用兼容修正：本机语言缓存为空时使用空对象，后台未定义脚本路径或版本标记时使用原生缓存目录和空版本号，避免语言包异步加载期间附件控件初始化报错。修正仅在源码精确匹配时执行，重复运行保持一致；原生缓存由 Discuz! 重新生成。

此仓库不包含 Discuz! 核心、数据库或任何管理凭据。部署时从官方仓库下载 `upstream.json` 固定的源码，并校验 SHA-256。Discuz! 保留官方版权；本仓库原创主题及部署工具采用 MIT 许可。

部署流程、管理员账号查看、备份和恢复见 [部署与管理说明](部署与管理说明.md)。论坛账号与聊天软件账号独立；论坛帖子由 Discuz! 数据库存储。

第三方邮件、短信和社交登录需维护者自行开通对应服务。仓库不会将它们标为已接入。
