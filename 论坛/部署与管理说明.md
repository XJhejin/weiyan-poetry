# 未言诗集论坛

访问地址：`https://bbs.hushleaf.top/`

Discuz! 管理后台：`https://bbs.hushleaf.top/admin.php`

论坛使用 Discuz! 官方简体中文 X5.0.4 开源版。发帖、回复、搜索、注册、私信、用户组、版主、附件、门户、群组和后台管理均由 Discuz! 原生程序提供。第三方短信、邮件、社交登录及官方收费服务需要各自的服务账号，部署不会虚构这些服务已开通。

初始版块为「-扉页-」「诗与远方」「日常拾光」「意见与回声」，可以在后台添加、修改和调整权限。默认会员组称为「掇花者」。论坛账号与聊天软件的账号独立，论坛帖子按 Discuz! 的方式保存在论坛数据库中，聊天软件的数据规则继续由聊天服务执行。

## 管理账号

初始管理员用户名为「掇花者」。部署会生成随机初始密码，通过当前管理员 SSH 会话加密传回，并使用部署电脑当前 Windows 账号的 DPAPI 加密保存于 `%LOCALAPPDATA%\WeiyanForumDeploy\credentials.dpapi`。

双击 `工具/查看管理员账号.cmd` 可查看和复制初始密码。请在首次登录后于个人设置中修改；修改后的密码不会自动写入这个初始凭据文件。公开仓库不包含数据库密码、SSH 密码、论坛初始密码或论坛用户数据。

## 服务器布局

- 程序：`/opt/weiyan/forum/current`，链接到固定上游提交的安装目录。
- 自定义模板：`template/hushleaf/`；主题静态资源：`static/hushleaf/`。
- MySQL：独立服务 `weiyan-forum-db.service`，数据位于 `/var/lib/weiyan-forum-db/data/`，仅使用本机 Unix socket，不监听网络端口。使用现有 MySQL 5.7 二进制，数据库 `hushleaf_bbs` 的应用账号仅拥有该库权限，不读取或修改面板原有数据库。
- PHP：`weiyan-forum-php.service`，独立系统账号 `weiyan-forum`，FastCGI 仅监听 `127.0.0.1:23274`。
- HTTPS：由现有 Caddy 提供，证书自动续期；现有 Nginx 的对应域名配置负责 HTTP 转 HTTPS。
- 敏感配置：`/etc/weiyan-forum/`；运行文件和 PHP 日志：`/var/lib/weiyan-forum/`。
- 部署记录：`/opt/weiyan/forum-deploy/deployment.json`。

安装目录、源代码目录、配置、数据库备份和缓存中的 PHP 文件不对公网开放，附件目录不能运行 PHP。Discuz! 核心保留官方版权和署名。本仓库只维护原创主题及部署工具，不重新分发上游核心。

## 备份与恢复

`weiyan-forum-backup.timer` 在服务器本地时间每日 03:30 创建数据库、附件、头像、论坛配置和主题的备份，保存于 `/var/backups/weiyan-forum/`，保留最近 14 组快照。数据库使用单事务导出。备份包含私有配置，仅服务器 root 可读。

恢复前先停止论坛 PHP 服务，将目标 SQL 导入 `hushleaf_bbs`，恢复对应文件快照，再启动论坛 PHP 服务。恢复时不要将旧程序目录直接覆盖其他应用目录。数据库导入及覆盖当前附件属于恢复操作，需要维护者确认所选快照。

## 主题和程序更新

`upstream.json` 固定官方源码提交和压缩包 SHA-256。部署工具会校验源码、运行官方安装器、通过原生模板导入接口应用主题，再检查公网 HTTPS 和原有服务状态。已完成安装时再次部署只更新主题与相关运行配置。

手机主题包含完整的 Discuz! 原生 touch 模板，包括板块列表、帖子详情、发帖、回复和个人空间，再叠加未言诗集的样式。手机与电脑读取同一套论坛数据库和附件，不需要分别发布或复制内容；权限、板块设置和帖子修改同步生效。手机版也显示置顶帖子，避免电脑有帖子而手机列表为空。不能只保留手机首页和页头，否则带板块编号的 DIY 模板可能无法回退，出现“没有手机页面”的提示。

工具面向当前服务器布局：PHP 8.2 位于 `/www/server/php/82/`，MySQL 5.7 位于 `/www/server/mysql/`，已有 Caddy 和 Nginx，远端维护 Python 位于 `/opt/weiyan/control/venv/bin/python`。迁移到其他服务器应先修改并审阅这些固定路径及 SSH 主机公钥。

Windows 维护电脑安装 Python 3.12 及 `requirements.txt` 后，运行以下命令。默认临时目录为本仓库 `.build/deploy/`，两个命令必须使用同一个目录。

```powershell
py -3 工具/start_session.py
```

此命令打开独立登录窗口。按回车，在 SSH 提示处输入服务器密码并保持窗口打开。脚本校验仓库中登记的服务器主机公钥，不保存密码、不添加 SSH 授权，也不扩大聊天控制端的权限。随后在另一个终端准备部署：

```powershell
py -3 工具/prepare_bundle.py
py -3 工具/capture_credentials.py
```

首条命令会从官方仓库下载并校验核心，将主题和工具打包为临时部署请求；第二条命令在部署完成后加密接收初始管理员凭据。后续重复部署不会重建已安装的论坛数据库。

如维护现有主项目中的部署会话，在以上各命令后统一追加 `--session-directory F:\未言诗集\.build\forum-deploy`。运行日志和部署归档均留在忽略的临时目录。

部署完成后，向会话目录的 `forum-requests/` 写入 JSON 请求 `{"id":"finish","operation":"quit","payload":{}}`，即可结束一次性 SSH 会话；也可直接关闭登录窗口。会话最长两小时。

`prepare_bundle.py --diagnose` 只排队检查固定服务和证书日志。`--repair-ip-renewal` 是当前服务器的专项维护选项，将原 IP 证书的 HTTP 验证切换为 Caddy 443 端口的 TLS-ALPN 验证，以避开 Nginx 对 80 端口的占用；普通主题更新不需要这个选项。

Discuz! 核心升级应先阅读官方说明、备份并在隔离环境验证，再更新固定提交和校验值。不能只更改 SHA-256 后直接覆盖一个正在运行的论坛数据库。

论坛单个附件上限为 1 GB（1,073,741,824 字节）。PHP 单文件限制为 1024 MB，请求总大小为 1088 MB，为表单开销预留空间；输入处理和 FastCGI 读写超时为一小时。附件直接写入临时文件，PHP 内存上限继续为 192 MB。

拥有附件或图片上传权限的会员组统一使用 1 GB 单文件上限，并取消每日累计附件大小额度，防止较小的每日额度拦截一个合法大文件；每日附件数量、会员组上传权限及禁止的扩展名继续由论坛后台控制。已有允许上传的扩展名采用相同的 1 GB 上限。再次运行部署工具会应用这一大小策略。

## 视频、音频、网页与手机签名

电脑和手机的完整发帖、回复、编辑界面，以及有文本框的快速回复区，增加「视频」「音频」「网页」按钮。可以粘贴 HTTPS 链接，或为音视频选择本地文件；点击「插入」后继续正常发帖。经典编辑器及原生 Editor.js 的文本段落均可插入，文本模式中会显示专用 BBCode。

宽度支持 1%–100%，或 120–1920 像素；高度为 40–1920 像素。默认宽度为 100%，手机显示不超过正文宽度。已发表内容的尺寸可在原生编辑页面修改，例如 `[hlvideo=640,360]attach:123[/hlvideo]`，其中 123 是该帖自身附件编号；外部音频和网页分别使用 `[hlaudio=100%,54]https://example.com/audio.mp3[/hlaudio]`、`[hlweb=100%,480]https://example.com/[/hlweb]`。

本地视频支持选择 MP4、WebM、OGV、MOV、M4V；音频可选 MP3、M4A、OGG、WAV、AAC、FLAC、Opus。能否播放具体编码由浏览器和系统决定，播放器保留「打开原文件」入口。上传沿用原生附件接口、归属绑定、用户组及板块限制，单文件最大 1 GB。播放通过当前会话的权限网关进入原生下载接口，保留附件阅读权限和付费检查；原生分块输出支持播放进度拖动，不将大附件整体载入 PHP 内存。

常见 Bilibili 视频页及 YouTube 分享链接可转换为对应播放器。任意网页使用沙箱 iframe，不允许取得论坛同源权限或直接控制顶层页面；目标网站的 CSP、X-Frame-Options 或浏览器策略可能禁止嵌入，此时使用「打开原网页」。不自动播放，不开放任意 HTML 或脚本发帖。媒体代码在代码示例、关闭 BBCode 的帖子以及签名中不执行，隐藏内容仍由原生解析器控制。

插件位于 `source/plugin/hushleaf_media/`，JS/CSS 位于 `static/hushleaf/media.*`。部署通过原生插件注册和缓存接口启用电脑与手机钩子，并为原本可发帖或回复的用户组及当前板块开启原生媒体代码权限，不增加发帖、上传或浏览权限。后台可继续调整这些权限；重新部署会重新应用媒体代码开启策略。`插件/hushleaf_media/selftest.php` 用于 PHP CLI 安全回归，不安装为网页入口。

手机完整帖子和异步单帖均显示原生已经过滤的签名；匿名、禁用签名、封禁和隐藏回复状态仍然生效，签名图片限制在屏幕范围内，并遵守论坛的签名高度设置。

邮件、短信及第三方登录没有预置真实服务账号，开通前无法使用邮件找回密码等外部服务。
