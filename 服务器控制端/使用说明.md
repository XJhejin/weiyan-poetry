# 未言诗集 · 服务器控制端

这是独立的 Windows 管理软件，连接部署在 `156.225.28.175` 的 Linux 服务端。它与聊天客户端、在本机运行服务的「服务端管理」是三个独立程序。

## 打开

双击 `安装包/weiyan-control-2.2.2-windows-x64.msi` 安装，桌面和开始菜单会出现「未言诗集服务器控制端」。本次部署使用的管理员电脑已经配置管理授权，安装后可直接打开。源码目录有打包程序时也可双击 `启动控制端.cmd`。

## 手动连接

1. 打开控制端，点击右上角「连接设置」。未连接时也可打开。
2. 填写服务器 IP/域名、SSH 端口和用户名。当前服务器为 `156.225.28.175`、端口 `22`、用户 `root`，这里填写 SSH 信息，不是聊天的 HTTPS 地址和 23074 端口。
3. 选择「SSH 密码登录」，输入服务器 SSH 登录密码。默认只在本次运行期间使用；需要重新打开后自动连接时，可勾选「记住密码」，密码会由当前 Windows 账号加密保存。也可选择原有管理密钥连接。
4. 点击读取主机指纹，通过服务器控制台或可信渠道核对，勾选确认信任，再保存连接。仅仅读取指纹不等于验证服务器身份。
5. 点击「保存并连接」。软件先验证登录及管理状态，成功才保存；失败保留原来的连接和授权。首次连接需核对主机指纹，后续连接会固定校验。密码和导入私钥不上传 GitHub。

状态区显示最近管理请求耗时和最近 30 次管理状态请求的失败比例；这不是聊天链路延迟或 ICMP 丢包率。

## 查看和管理

- **运行概览**：服务器实际在线用户、账号数、连接、待投递密文和运行时长；内存、磁盘、负载与 HTTPS 代理状态。可停止/启动聊天接收或重启聊天服务。关闭控制端不影响服务器继续运行。
- **账号与设备**：搜索用户名和昵称，查看头像、账号状态、注册时间、设备编号与最近活动；可停用/启用账号、退出账号登录、重置头像、撤销设备。
- **隐私与存储**：查看服务器数据位置、密文保留规则，设置是否允许注册及访客登录。
- **软件更新**：检查 GitHub 正式发布的 Linux 版本，显示发布说明，点击「下载并重启安装」执行远程更新。任务在服务器继续执行，重新打开控制端仍能查看进度和结果。
- **运行日志**：点击刷新，读取最近的聊天服务运行日志。

密码仅保存验证用的散列，控制端不显示密码；聊天内容由客户端加解密，控制端不能读取正文。

## 更新保留什么

只接受项目内置公钥验证通过的 GitHub Releases 清单及 SHA-256 一致的 Linux 源码包。先在新目录准备依赖，切换前短暂停止公网入口和聊天服务，用 SQLite 备份数据库，再启动新程序。健康检查失败时恢复旧程序和更新前数据库，然后恢复公网入口。账号、设备、群关系及待投递密文位于独立数据目录；不会安装 Windows ZIP 或 Mac DMG 到 Linux。

更新需要服务器能够访问 GitHub 和 Python 包仓库。后台运行目录为 `/var/lib/weiyan-control/`，程序版本目录为 `/opt/weiyan/versions/`。数据库备份和旧版本保留供管理员恢复，不会自动删除未投递消息。

## 管理授权

本机授权配置位于 `%LOCALAPPDATA%\WeiyanPoetryControl`，SSH 私钥由 Windows DPAPI 绑定原电脑和原账号加密保存，运行时临时解锁到仅当前用户可访问的目录，正常退出删除。不要将此目录、私钥或服务器数据库传到 GitHub。

密钥连接通过 Windows 内置 OpenSSH，服务器仅允许受限管理密钥执行指定管理程序，禁止任意 shell、端口/代理/X11 转发及 PTY。密码连接通过随程序打包的 SSH 库，关闭代理和密钥自动尝试，固定运行 `/opt/weiyan/control/venv/bin/python /opt/weiyan/control/control_gateway.py`，不提供命令行或 PTY。两种方式均固定校验服务器主机密钥；服务器需已部署管理组件，且 SSH 账号有权运行它。控制端不修改服务器的 SSH 密码登录设置。

管理网页仅在服务器 `127.0.0.1:23175` 开放，聊天后端 `127.0.0.1:23174`；用户聊天入口为 `https://156.225.28.175:23074`。勾选记住的 SSH 密码也使用 DPAPI 绑定当前电脑与 Windows 账号；取消记住并成功保存连接后，删除此前保存的密码。密码不会写入命令行参数、环境变量或日志。

公开 MSI 不含管理授权。换电脑或 Windows 账号后，可以在连接页面输入有权限的服务器 SSH 密码；使用密钥时，需要管理员为新电脑登记独立的强制命令公钥，并在新电脑导入私钥、核对主机公钥。复制安装包不会复制管理权限。撤销密钥时，从服务器 `/root/.ssh/authorized_keys` 删除对应 `weiyan-control-...` 公钥行；不要删除其他 SSH 登录授权。
