# 未言 · 羽音签名

依据用户提供的音符草图，为原创角色「未言」设计的个人签名标记。

双弧音符构成主体，符头融入羽毛笔形的长收笔，右侧保留一枚小星芒。整体无边框，使用冷栗棕与低饱和灰粉色，呼应角色的栗色水母头、羽毛笔发夹与轻冷气质。

| 文件 | 用途 |
| --- | --- |
| `未言-sign-栗棕.svg` / `.png` | 栗棕主版，配灰粉星芒，适合浅色背景 |
| `未言-sign-黑色.svg` / `.png` | 纯黑单色版，适合印刷及单色署名 |
| `未言-sign-白色.svg` / `.png` | 纯白版，适合深色背景与作品角标 |
| `未言-sign-预览.png` | 浅色、深色与缩小使用效果展示 |
| `预览.html` | 可在浏览器直接打开的本地展示页 |

主色 `#59464B`，点缀色 `#B89CA9`。三份 PNG 均为 2048 × 2048 像素、真实透明底；SVG 以路径绘制，无字体或外部图片依赖，可交给画师缩放和调整。展示页背景与文字不包含在签名原稿中。

用于新设计稿的主版；现有网站与软件资产另行维护。
