# 未言 · 梦羽

按照用户的修改方向，将符头设为具有梦境混沌感的旋涡云，符杆设为羽毛笔，整体使用圆润卡通造型，并提供挂坠设计稿。

符头的外形由不规则云团组成，内部用交叠雾色、弯曲旋涡、月牙与星屑表现梦境。羽毛笔采用银灰、灰紫色，保留音符的双弧轮廓；栗棕灰描边和少量灰粉色呼应角色配色。

| 文件 | 用途 |
| --- | --- |
| `未言-sign-v2-梦羽.svg` / `.png` | 卡通签名原稿，透明底 |
| `未言-sign-v2-挂坠设计.svg` / `.png` | 带连贯浅色外沿、顶部悬挂孔的设计稿，孔位透明 |
| `未言-sign-v2-预览.png` | 原稿及挂坠造型展示 |
| `预览.html` | 浏览器本地展示页 |

两份 PNG 均为 2048 × 2048 像素。SVG 为可编辑路径，渐变、描边和遮罩均包含在文件内，无外部图像或字体依赖。

挂坠造型将装饰集中在主体内，外沿和悬挂环相连。展示中的链条与阴影仅用于说明佩戴效果，不包含在透明原稿中。制作方可在 SVG 基础上调整成品尺寸、孔径和生产刀线。
