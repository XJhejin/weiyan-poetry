数据保存规则

聊天记录
保存在各自客户端本机，使用独立密钥加密；Windows 使用 DPAPI、安卓使用系统密钥库保护密钥。
离线消息
仅暂存密文。未送达时永久保留，收到客户端确认后删除。
账号与连接信息
保存账号、密码散列、公钥、会话成员与必要的投递元数据。服务端可见谁与谁通信。
公开聊天室
消息向发送时已登记的成员设备加密分发。任何已注册成员均可参与。
这是本项目基于 libsodium 实现的加密协议，尚未经独立安全审计；不具备 Signal 双棘轮的前向保密能力。

离线投递设置

密文保留时间
永久保留，直至接收设备确认。
队列容量
不设软件容量上限，按实际磁盘可用空间保存。

离线时长不会导致消息被清理。已撤销设备对应的投递项会移除。
