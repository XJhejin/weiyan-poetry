未言诗集

愿未尽之言，皆有回响。

安装与启动

Windows 客户端双击 MSI 安装，自动创建桌面和开始菜单快捷方式。Android 手机安装 APK。Apple Silicon Mac 服务端打开 DMG，拖入 Applications；首次打开需在系统设置确认来源（尚未 Apple 公证）。Windows 服务端使用完整 ZIP。

默认服务端端口 23074。发布客户端连接 156.225.28.175:23074，需要该地址实际部署并开放端口；公网登录建议配置 HTTPS。

① 启动服务端

打开服务端文件夹，双击：

未言诗集服务端.exe

管理窗口显示“服务正在运行”后，保持窗口开启。

② 打开客户端

打开客户端文件夹，双击：

未言诗集.exe

创建账号或使用访客身份，即可进入聊天界面。发布默认连接 156.225.28.175:23074，同机测试请设置 127.0.0.1:23074。

与另一台电脑上的朋友聊天

  1. 两台电脑连接同一个 Wi-Fi 或局域网，选一台运行服务端。
  2. 把完整客户端文件夹复制给朋友，包括 _internal。
  3. 服务端管理窗口的“运行概览”中复制局域网地址。朋友在客户端登录页点击“连接设置”，填入该地址。
  4. 双方使用各自账号，连接同一服务端。进入公共聊天室，或点击 + 搜索账号后私聊。

发布默认地址 https://156.225.28.175:23074。局域网需允许对应防火墙端口；公网部署需另配 HTTPS。

你的数据如何加密

文字、图片、视频与文件端到端加密：发送前在客户端加密，接收设备解密。服务端没有消息解密私钥。

本机加密保存：记录、草稿、收藏、图片与待发消息在本机加密保存；断网重启后仍可查看已收内容。

离线消息永久待投递：服务端不设到期时间，不设队列总容量限制；接收设备确认保存后删除。实际存储取决于磁盘可用空间。

聊天顶部“端到端加密”、输入栏和“设置 → 加密与隐私”可查看说明与设备指纹。请通过可信渠道核对指纹；新增或更换设备需确认。新电脑登录不会恢复旧记录。

服务端仍可见账号、设备、会话成员和投递时间。公开聊天室向已登记成员设备分发。自建加密协议尚未独立安全审计，也没有双棘轮前向保密能力。

服务端管理

运行概览：启动或停止聊天服务、配置监听范围和端口、复制连接地址、查看在线成员与密文队列。

账号与设备：搜索账号、启用或停用成员、退出登录、撤销丢失设备。

隐私与存储：查看保存规则，设置是否开放账号和访客注册。管理界面只在服务端本机开放，不显示聊天正文。

好友、群聊与附件

公共房间只有「-扉页-」。搜索支持 @用户名或昵称，提供私聊与添加好友。好友需对方同意，未添加好友也可私聊。

群聊支持邀请、群主与管理员、踢出、改群名和头像、公告、禁言、群昵称、转让与退群。

图片、视频和文件可拖入输入区域；视频支持发送前预览和聊天内播放。图片最大 5 MB，文件/视频每项 20 MB。

Windows 关闭窗口后继续在托盘运行；托盘菜单可退出。Android 首次使用请求通知权限，后台接收依赖前台服务；系统强行停止后需重新打开。提醒不显示聊天正文。

常用操作

Enter 发送；Shift + Enter 换行。切换会话保留草稿。

右键消息可回复、复制和收藏；右键会话可置顶、免打扰；Ctrl + K 搜索本机记录。

左下角头像可以编辑资料。访客应先设置正式账号与密码，再退出登录。图片支持选择及粘贴，单张最大 5 MB。

检查和安装更新

客户端：设置 → 软件更新，或登录页底部“检查更新”。服务端：左侧软件更新。

从 GitHub 正式版本获取更新，验证发布签名和文件哈希后安装，失败时恢复旧文件。安装会重启软件，并保留客户端资料与服务端 data。

下载新版本时请完整解压，不要只复制 exe。两个软件各自的 _internal 都要保留。Windows 10/11 x64，需具备 Microsoft Edge WebView2；不需要安装 Python。

记录和备份

客户端加密资料位于 %LOCALAPPDATA%\WeiyanPoetry\client。服务端账号、公钥和待投递密文位于 服务端\data。

先退出软件，再分别复制完整资料目录。密钥受原电脑和原 Windows 账号保护，直接复制到其他电脑不能保证解锁。

旧版升级时，服务端旧记录会先转入同机客户端资料目录下的加密归档，再清除服务端旧明文。使用原账号在同机客户端登录后导入。
